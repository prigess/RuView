RuView Sensor catalogwhat plugs into an ESP32-S3 · how each helps elder-care

Everything below plugs into an ESP32-S3 with minimal wiring (Qwiic / Stemma-QT / Grove, or 2-4 jumpers). Each card carries a consent tier: default always-on, no PII; opt-in caregiver toggle, anonymous signal; explicit biometric per-person consent + revocable enrollment. Plus interface, cost, and ease.
