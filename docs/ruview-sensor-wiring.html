Read this first

These three pinouts are the canonical build pulled straight from the working ESPHome / firmware configs. Wire every new node exactly like this and the same firmware flashes with zero changes.

⚡ Power rail is not optionalRadars (LD2410C / LD2450) need 5V — 3.3V gives no data or flaky data. The mic (INMP441) is 3.3V — do not feed it 5V.
✅ 5V pin already fixed on our boardsThe YD-ESP32-S3 5V jumper has been bridged on every board in the fleet, so the 5V0 pin is live (~5V). Radars power straight from 5V0 — no per-build jumper step. (Only relevant again if you buy a brand-new unbridged board.)
📍 All our pins are on the LEFT header · silkscreen, not positionOn this dual-USB-C board every wire lands on the left-side header. The radar cluster (5V0 · GND · GPIO11 · GPIO12) sits together at the bottom-left corner; the mic pins (3V3 · GPIO4 · GPIO15 · GPIO16) are in the upper/middle-left. The GPIO11/12 slot is often mis-counted as "pin 17/18" — always go by the printed GPIO number. Avoid GPIO19/20 (USB) and GPIO43/44 (serial log).

LD2410C — 24 GHz presence + moving/still distance (single target)

4 wires. Presence, distance, and energy for one aggregate target.

LD2410C pinESP32-S3 (silkscreen GPIO)
powerVCC 5V0(live)
groundGND GND
radar outTX GPIO12(S3 RX)
radar inRX GPIO11(S3 TX)

5 V power UART 256000 8N1   Config: ruview-s3-ld2410c.yaml

Baud noteFactory default is 256000; some batches ship at 115200. If you get no target data, try 115200 in the YAML once, then set it back.

LD2450 — 24 GHz multi-target tracking (up to 3 people, X/Y)

Same 4 wires as the LD2410C — identical pin map. The only difference is the sensor and the firmware component; the wiring does not change.

powerVCC 5V0(live)

Standardization winRadar nodes are wire-interchangeable: a LD2410C harness fits a LD2450 with no rewiring. Only the flashed YAML differs.

INMP441 — I²S MEMS microphone (audio / sound-class sensing)

6 wires. Different pin cluster from the radars, and 3.3V — not 5V. Tie L/R to GND for the left channel.

INMP441 pinESP32-S3 (silkscreen GPIO)
powerVDD 3V3(NOT 5V)
groundGND GND
channel selL/R GND
bit clockSCK GPIO15
word selectWS GPIO16
data outSD GPIO4

3.3 V power I²S (left channel)   Config: audio_streamer_main.c / ruview-s3-mic-n2.yaml

Do not swap the railINMP441 is a 3.3V part. Feeding it 5V from the radar harness can damage it. Keep radar and mic harnesses visually distinct.

No pin conflict between radar & micThe radars use GPIO11/12; the mic uses GPIO15/16/4. They don't overlap — so a single ESP32-S3 could run one radar + the mic together on a future combo node without changing any of these assignments.

Wire-color convention (suggested, keep it consistent)

  • ■ Red → 5V  ·  ■ Orange → 3.3V  ·  ■ Black → GND
  • ■ Green → TX/data-out  ·  ■ Teal → RX/data-in
  • Radar harness = red power; mic harness = orange power. Never mix.
